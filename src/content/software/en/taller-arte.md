Website for TallerArte, with an artwork catalogue and navigation in three
languages (Spanish, English and French) through Astro's internationalised
routing.

## Technical details

- Content collections for the catalogue, with schema validation at build time.
- i18n routing with Spanish as the default language.
- Static site: no server to maintain and no database.
